# 开发路线图

## 原则

- 先验证完整闭环，再增加内容量。
- 规则系统先于 LLM 成熟；LLM 是增强层，不是运行前提。
- 每个里程碑都必须可运行、可测试、可观察、可回放。
- 未通过验收的能力不标为完成。

## Milestone 1：最小可运行原型（已完成）

**目标**：可运行的上帝视角像素世界；20 个 NPC；时间控制；基础寻路与决策；选中查看；确定性；日志。

**已完成**：

- Tuanjie/Unity 2022.3 兼容项目结构与程序集隔离。
- 64×64 地图与村庄、道路、水塘、农田/房屋占位、森林、岩石。
- 20 个 NPC、稳定 ID、性格占位、需求数据占位、规则 Rest/Wander。
- 确定性 A*、固定 tick、状态哈希。
- 自由相机、像素吸附、NPC Y 排序、昼夜色罩。
- uGUI God View：时间/速度、NPC 检查器、事件日志、调试面板、生成 NPC 命令。
- 会话 JSONL 与回放摘要。
- EditMode 9 项测试、PlayMode 2 项测试。

**明确未做**：需求衰减、种植、动物、狩猎、交易、关系、记忆、存档 UI、LLM、正式美术、中文 UI 字体。

---

## Milestone 2：生存与资源循环（核心功能与自动验收完成）

**目标**：NPC 能依靠需求、资源和简单计划生存。

- 需求衰减：饥饿、口渴、疲劳、健康、安全。
- 食物/饮水/睡眠行动，背包与库存。
- 农田、作物定义、生长阶段、浇水、收获、土地肥力。
- 采集节点与再生。
- 效用目标选择 + 有限领域多步计划（前置条件/效果组合，非通用 GOAP 搜索）。
- 行动失败、重规划、资源保留与占用。
- 为 M1 的调试面板增加“需求历史”和“计划解释”。

**出口标准**：

- 无人干预至少 7 个游戏日仍可运行。
- NPC 能自行处理基本饥饿/疲劳，不会出现资源复制或负数库存。
- 同种子与相同非空命令序列产生相同状态哈希；完整回放播放器在 M4 实现。
- 关键行为都能在 UI 中看到原因。

---

M2 验证：原工程 EditMode 43/43、PlayMode 4/4 通过；默认 20 NPC 的 7 日生产/消耗与健康检查通过。HUD 布局与需求曲线已查看，原生鼠标交互人工复验仍待完成。详见 [M2 记录](Progress/Milestone-02.md)。

## Milestone 3：狩猎与交易（核心切片与自动验收完成）

**目标**：出现生态与经济的互动，NPC 形成不同生存策略。

- 动物实体与种类定义、游荡/逃跑/繁殖/死亡。
- 狩猎行动：工具、技能、体力消耗、风险、受伤、掉落。
- 市场：钱包、库存、订单、交易账本、动态价格、供需。
- 职业差异：农夫、采集者、猎人、商人、建造者。
- 动物种群与市场价格都能在观察面板中查看。

**出口标准**：

- 连续 14 个游戏日经济不崩溃，货币和物资守恒。
- 交易原子化，失败可解释。
- 至少三类 NPC 出现明显不同的资源策略。
- 动物数量不会无限增长或瞬间灭绝。

---

M3 验证：原工程 EditMode 92/92、PlayMode 见最新记录；四个固定种子各完成 14 游戏日，物资/货币逐 tick 守恒、每日买卖、账本独立核对、三类实际资源策略和有界种群通过。当前为有保护数量的生态与公共库存保障加有限市场的混合经济；建造者仍用通用工作。M3 收尾的 [32×32 美术与中文交互升级](Progress/Milestone-03-ArtUpgrade.md) 已完成首版，验收分辨率仅 1920×1080。详见 [M3 记录](Progress/Milestone-03.md)。

## Milestone 4：存档、社会关系与观察（首版切片已实现）

**目标**：世界可保存恢复；NPC 记住互助经历，信任影响后续选择，玩家能观察原因。

- 版本化存档/迁移、原子写入、手动保存加载、每日自动保存与备份。
- 完整恢复行动路径/计划/预留、生态市场、随机流、社会状态和待执行命令；失败保留当前世界。
- 单向信任、问候和赠食，有限事件记忆、优先保留重要帮助经历。
- 信任影响实际帮助对象；人物档案和可筛选时间线展示受助/回报原因链。
- 四种子中途恢复后逐 tick 哈希一致；14 日生存、守恒、每日交易与真实社交回归。

**本次边界**：没有债务、恐惧、争执、谣言、完整回放播放器和长期记忆摘要。这些不作为当前切片完成能力；LLM 属于 M5。

实现、验证与手工检查见 [M4 记录](Progress/Milestone-04.md)。

## Milestone 5：首批 LLM NPC

**目标**：少量核心 NPC 使用 LLM 做高层决策，规则系统仍是执行与回退层。

- Provider 抽象：OpenAI-compatible / 本地模型。
- 结构化 `IntentProposal` schema 与验证器。
- 上下文构建：身份、需求、库存、关键关系、Top-K 记忆、允许目标。
- 异步队列、超时、重试、限流、熔断、成本统计。
- 每日预算/每 NPC 配额/缓存。
- 选择 3-5 个核心 NPC 启用；其他 NPC 全部规则驱动。
- 记录决策理由、输入摘要、延迟与回退原因。

**出口标准**：

- 关闭 LLM 时游戏功能不降级到不可玩。
- LLM 不能直接改世界，非法/过期意图被拒绝。
- 超时或断网自动回退，不阻塞主线程。
- 回放使用记录下来的 LLM 输出，不重新调用模型。
- 可看到每日 Token/成本/命中率与回退统计。

---

## Milestone 6：多智能体世界与规模化

**目标**：扩大人口和长期演化，同时控制性能、成本和内容制作。

- 50-100 个 NPC。
- 长期记忆压缩与检索；关系网络和合作/竞争任务。
- 契约、群体、声誉、职业发展。
- 分批决策、路径预算、视图池化、地图区块化。
- 更多地图与资源；内容数据化。
- 30 游戏日 soak test、存档迁移、回放。
- 评估离线演化（关闭游戏后的追赶模拟，使用规则 AI）。

**出口标准**：

- 目标规模下稳定 60 FPS，无明显 GC/内存增长。
- 30 个游戏日自动运行无结构性异常。
- 存档、回放、LLM 记录和成本都可控。
- 世界在没有 LLM 的情况下仍能长期演化。

## 自主生存扩展：狩猎、种植与打水

按资源与建设、水循环、农业、狩猎救治、整体验收五阶段实现。NPC 自主建造五类公共设施，使用三类作物、三类猎物、四种耐久工具、生水净化与药品救治；玩家保持观察与干预视角。

新规则使用存档 v3 / 哈希 v5，旧版本重新开局。验收包含所有物品/货币守恒、四种子 14 日回归、默认种子完整 112 日、途中保存恢复和受控危机场景。实施与测试证据见 [自主生存扩展记录](Progress/Survival-Expansion-2026-10-22.md)。

## 下一步

完成自主生存扩展的原生交互复验后，再推进 M5 的只读上下文、高层意图验证与异步网关。LLM 仍默认关闭。复杂管网、人口繁殖、完整原材料市场与历史回放播放器不在本轮范围内。

## 协作狩猎升级（2026-10-24）

完成即时动物反应、可达逃生路线、鹿踢击、野猪分段冲锋与狼群响应；狩猎任务支持最多三人分工、真实装备准备、射路避让、撤退救援、唯一尸体回收和返村存放。玩家通过动物详情标记目标、选择队员及取消任务。攻击动画按阶段播放，新像素帧使用独立图集。

新规则采用存档 v5 / 哈希 v7，旧文件保留并要求重新开局。本轮不增加陷阱、猎场建筑、装备等级、成长树或直接战术控制。实现、已完成验证及画面证据见 [狩猎升级记录](Progress/Hunting-2026-10-24.md)；按用户要求停止后续测试，最终表现微调的 PlayMode 复验状态在记录中注明。

2026-10-25 按原方案复核并补齐补装、动态危险评估、退路检查、冲锋侧移、前方截击、遮挡信息边界和回收交接；已完成快速代码与狩猎定向画面检查，范围及证据见 [完成情况复核](Progress/Hunting-Completion-2026-10-25.md)。

后续针对玩家自动狩猎反馈，复现并修复 NPC 挡路时反复走回原路、截击点反复重选／超出射程、未曾目击就失联撤退，以及正常返村误标失败；增加十四项代码回归，继续沿用独立代码验证。

## 冬日种植与寒温带动物生态（2026-10-25）

将三类作物统一为耐寒菠菜、羽衣甘蓝与羊生菜，引入真实建材、有限木材供暖和维护的保温菜床；玩家按田设置种植／休耕，按床设置供暖优先级，NPC 执行建设、清雪、照料与有限复采。农作物读取土温、日照、水和覆雪，成熟作物继续受损，冬季不返还种子。既有右侧详情与独立像素图集呈现状态。

寒温带七种动物共享可食份额、雪下／地表活动和物种繁殖窗口规则；冬季残果、种实和根系有限，野外食物节点不再把灌木总量直接转换为新鲜浆果。保留真实迁徙与唯一死亡／尸体结算。新规则使用独立存档 v7 / 哈希 v9，旧存档保留并要求新开局。

本轮默认种子的目标是第七日前实际农业交付、第十四日前复采，农业只补充生存食物；四种子回归保留真实死亡和断供结果，不保证无人干预全员生还。完整代码、EngineSmoke、农业定向交互和三分辨率画面证据，以及验证边界见 [本轮验收记录](Progress/Winter-Farming-2026-10-25.md)。制种生产链、完整温室建筑和旧存档迁移不在本轮范围内。
