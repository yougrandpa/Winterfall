# 狩猎系统完成情况复核

日期：2026-10-25（北京时间）。本记录接续 [首轮狩猎升级](Hunting-2026-10-24.md)，依据源码和受控场景核对原方案。

## 本轮发现并补齐的缺口

| 环节 | 原有缺口 | 本轮完成 |
| --- | --- | --- |
| 组队准备 | 未装备但有真实库存可领的队员无法入队；组队未核对共享库存总量 | 招募按猎人、装备适配、路径、技能、ID 排序；最多三人的装配组合先校验库存，显式名单仍整体拒绝，不替换成员 |
| 武器与箭 | 集结补给可能空等；首名弓手可能拿走其他队员最后一支箭 | 从背包或公共库存装备真实武器，为其他弓手留出最低箭量；补给缺失或不可达立即退出准备，沿用生产链 |
| 集结与追猎 | 返回集结点的分支可能绕过三十 tick 上限；失去目击后撤退又在同次更新重新预留目标 | 全阶段检查期限，撤退后保持释放；自主招募失败也进入六十 tick 冷却 |
| 驱赶与截击 | 两人围鹿缺少明确截击角色；侧翼仍可能从后方直接开弓 | 两人鹿队分出侧翼，优先前往最后目击运动方向前方的可达工作格；分配不同工作格、避免占位并在必要时绕行；射位暂时被队友占用时等待或换位，不能误判为接近不可达 |
| 动态求生 | 狼群承受能力只在组队时检查；退路未持续检查；疲惫或有紧急需求的矛手仍可能掩护攻击 | 每 tick 按队员实际可感知的狼群复查风险与退路，武器失效或箭耗尽停止追猎；仅健康、有体力且无紧急需求的矛手短时掩护 |
| 冲锋躲避 | 已经拉弓的猎人不会进入移动分支，可能站着承受冲锋 | 可见冲锋预警优先于攻击，取消尚未释放的攻击并侧移一格，检查两侧障碍和占位；不读取隐藏冲锋者的位置 |
| 遮挡信息 | 受击直接读取攻击者位置；瞄准朝向可能跟随隐藏目标 | 动物只记住已感知位置或箭的来向，攻击者死亡仍可触发逃跑；弓使用最后可见信息作最多两格的有限预判，不读取隐藏目标的新位置 |
| 回收与中断 | 回收者交接的短暂空档可能被其他 NPC 抢占；离队者的未释放攻击可能继续 | 原任务持有尸体回收权限，其他规划器跳过；离队统一取消尚未释放攻击，已离弦弹道保留 |
| 玩家反馈 | 装备候选信息笼统，取消无效任务缺少中文原因 | 显示风险、已装备和待领／待补箭状态；无效取消返回中文原因，成功干预仍按原规则标记辅助成绩 |
| 攻击与画面 | 最后一次阶段帧调整没有新证据；按钮测试有绕过 UI 射线的回退 | 阶段取帧提到纯 C# `CombatAnimation`，覆盖蓄力、出手、冲锋和恢复；移除回退，按钮必须通过实际 EventSystem 射线命中；重新拍摄狩猎画面 |

新增状态均复用既有任务、装备、攻击及冷却字段，无新增权威存档字段。外壳／世界快照 v5、哈希 v7、回放摘要 v6、独立 `saves-hunting-v5` 目录保持不变。未重建 Bootstrap、重置世界配置或修改图集切片。
