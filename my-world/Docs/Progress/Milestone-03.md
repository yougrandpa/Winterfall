# Milestone 03：动物、原子交易与 14 日生态经济验证

日期：2026-10-21  
状态：**核心切片、自动验收与 Game View 视觉检查完成；原生鼠标人工复验沿用 M2 待办**

## 实现范围

### 动物与狩猎

- 兔和野猪使用稳定全局实体 ID、独立生态随机流和每只动物的随机状态，按 ID 顺序更新；出生不会改变现有 NPC 的随机流。
- 动物在可行走格上游荡，附近有携带狩猎工具的 NPC 时逃跑。成年动物成对繁殖，有年龄、生命值和自然死亡；死亡实体移出活动列表。
- 每类初始 12 只、容量 24；每 240 分钟检查繁殖，成年门槛 1440 分钟。种群剩余 4 只时停止狩猎。这是明确的保护规则，不是已经验证的自然生态平衡。
- 猎人携带弓，追踪已预留的移动猎物，最多追逐 120 分钟；每次攻击消耗体力、提升技能，并根据种类承担受伤风险。兔/野猪分别掉落 3/5 食物。
- 击杀前再次检查存活、预留、距离、工具、体力、健康、保护数量与完整掉落容量；掉落只产生一次。紧急需求、失去目标和失败均释放猎物预留。

### 市场与账本

- 村庄库存位置兼作交易地点；独立市场容量 600，初始食物/饮水/种子各 30，国库 2000，每个出生 NPC 获得 100 枚货币并计入发行量。
- 市场接受立即成交或拒绝的订单；尚无挂单撮合簿。所有交易在 tick 中执行，NPC 的计划步骤或 `TradeCommand` 都走同一个结算入口。
- 检查订单 ID、角色、物品、方向、数量、位置、报价、库存、容量和资金后，一次性交换物资与货币。重复/乱序 ID 不再结算；失效报价、资金不足、满包等失败可解释。
- 价格每小时根据市场库存变化，范围 1..12，稀缺涨价、过剩降价。买卖使用同一报价；没有税、利息、凭空补充国库或无限市场货源。
- 账本保留不可变订单、成交/拒绝原因、双边物资和资金的前后值。完整历史在模拟中追加保存，并以结构化 `trade` 记录写入会话 JSONL；HUD 显示最近两笔，快照保留最近四笔。
- 农夫偏好作物，采集者偏好可再生食物，猎人偏好猎物，商人偏好饮水供给和出售余货；建造者仍使用通用生存工作，没有建筑系统。
- 生产者出售部分产物，其余进入公共库存。NPC 有钱且市场有货时购买所需物品；缺钱/缺货时仍可使用公共库存与采集。这是公共生存保障加有限市场的混合经济，尚未验证完全依靠付费交易的经济。

### 守恒、确定性与观察

- 逐类计量初始量、生产量、消耗量；检查 `当前物资 = 初始 + 再生/收获/狩猎 - 进食/饮水/播种/浇水`，转移和买卖不改变总量。活体动物不计为背包食物，狩猎掉落是显式食物来源。
- 检查 `国库 + 所有钱包 = 已发行货币`。运行中生成 NPC 的初始货币也记入发行量。
- 状态哈希升级为 v3，包含动物、随机流、预留、钱包、工具/技能、实际生产计数、计划报价、市场供需、价格、物资来源/消耗与账本摘要。不可变完整账本在追加时更新摘要，避免每 tick 重算全部历史。
- 回放摘要格式升级为 v2，并标明 `StateHashVersion = 3`；M2 哈希不能直接与新规则比较。完整存档恢复/回放播放器仍属于 M4。
- 表现层使用不可变生态经济快照；显示动物占位像素图、种群、价格、市场库存、成交/拒绝、国库和守恒误差；NPC 检查器显示钱包、狩猎工具/技能与实际职业产出。

## 边界
