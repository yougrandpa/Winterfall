# 狩猎准备、耐力与完整流程验收

日期：2026-10-25（北京时间）。本轮接续狩猎完成情况复核，落实真实准备、自动潜伏、长矛近战和多物种猎获，并将验收推进到实际返村结算。

## 实际改动

- 短期耐力与长期精力分离。低耐力缓行恢复，恢复期间停止主动攻击，零耐力仍可移动；睡眠、医疗、断粮断水与失温保持各自的安全退出逻辑。人物档案单独展示短期耐力，任务展示耐力与精力、随身食水及冬衣。
- 狩猎在仓库附近集结，准备上限 90 tick。全队武器、四支箭／弓手、食物、饮水和必要冬衣先校验真实库存并预留，再领用、进食、穿戴及休息。预留物资与工作格分开，取消和撤退立即释放未使用物资；野外可在安全情况下使用随身补给。
- 动物不再根据任务或目标预留产生危险信息。识别距离区分潜伏与正常接近，受击、真实声响和箭矢掠过才提供对应惊扰；狼群也依据实际遭遇响应。接近未警觉猎物自动潜行，追赶与恢复使用不同移动节奏。
- 长矛猎人使用相邻工作格、截击和短时掩护，有独立持械与潜行帧。队伍弓手按最后目击运动作有界预测，稳定潜伏射击减少散布；最后一支已离弦箭完成结算后才判断弹药耗尽。
- 兔／狐／狼提供毛皮，野猪／鹿保留兽皮，渡鸦提供羽毛，田鼠主要提供少量生肉。尸体产物仍属于有限生态生物量，实际回收时才转成库存物品；腐败、满包交接、剩余猎获和返村交货覆盖全部产物。新增毛皮制冬衣和羽毛制箭的替代配方，批次使用稳定配方 ID 并随存档恢复。
- 地图接入持续尸体与有限掉落图标；新 `HuntingFieldAtlas.png` 包含 388 个切片。独立生成新图集，旧图集、切片槽位、Bootstrap 与世界配置保留。
- 任务保留逐人实际返回的位置和时刻，求生接管后继续追踪。最近十六项结果保留参与者、失败原因及实际入库数量；先返村的人可恢复日常工作。满仓时保留实际背包物品，不报告虚假的入库数量。

存档外壳／世界快照 v6、生态块 v2、战斗块 v3、哈希 v8、回放摘要 v7；新目录为 `MyAiWorld/saves-hunting-v6`。旧文件保留，旧版本明确提示重新开局。

## 验收中发现并修复的问题

1. 最初四项新用例先复现：移动消耗睡眠精力、远处标记野猪直接产生冲锋、集结点未设在村庄，以及缺少食物仍能发布任务。修复后再扩展为耐力、准备、物种产物、替代配方、存读档、返村、搜索和队友导航回归。
2. 准备途中天气变化可能新增冬衣需求。到仓库后可从尚未预留给他人的真实余量领装，不能凭空产生冬衣或挪用别队物资。
3. 已穿冬衣且体温安全的猎人不再单因冬季夜晚触发普通村民的提前取暖中断，仍按预计往返暴露和实际体温判断风险。
4. 未目击猎物时，原逻辑会停在旧标记的弓箭射程外。现改为抵达最后已知位置并搜索已知邻格；共享当 tick 的目击仍支持侧翼截击。
5. 原近失判断会在箭尚未到达时提前向动物发布警报。现仅在箭真正掠过时记录近失，保留有限来向信息；不读取隐藏射手实时位置。
6. 狭窄通道内，移动队友原先会封锁整条未来路线。现在规划允许考虑正在前进的队友，但实际下一步仍校验占位；静止阻挡继续绕行和有限等待。
7. 返村验收改为核对每人的真实到达记录，不能把“最后一人到达时其他人已恢复工作”误判成未返村，也不能把解除任务预留误判为到达。
8. 原受伤画面用例假设发令后立刻交战，与新增的真实准备阶段不相符。画面用例现先建立明确的初始防御遭遇、执行真实准备，再检查冲锋与出手，最后注入受伤以检查撤退显示。这项受控画面测试与下面发令后无状态覆盖的完整流程分开报告。

9. 收尾一致性检查增加离队后的耐力恢复用例：恢复到阈值后同时清除恢复标记与显示模式，避免已恢复仍显示“恢复中”。该修复后重新执行完整代码与最终引擎验收。
10. 提交前审查先用回归复现最后一名队员在村内中断计划时重复结算：`Detach` 已完成任务，`Update` 仍访问任务副本并再次完成。现以从活动列表移除任务作为唯一结算入口，重复调用不会重复写结果。
11. 提交前审查补充毛皮冬衣和羽毛箭矢的缺料用例：已暂存的替代配方曾在另一材料短缺时切回原配方。现保持同一产物的待加工配方 ID，补货前及存读档后均保持批次。新增三项用例先失败，再修复至通过；本轮提交前完整代码回归为 499 项。

十四日回归曾发现零猎获，保留真实猎获断言后修复追踪、近失与弹药结算。随后所有职业行为、逐 tick 物资／货币守恒及真实猎获断言通过，最后才更新哈希基线：`2275f8185d94410e` → `2d1d15c4fce4a6d5`。没有删除或放宽行为断言。

## 完整流程与证据

完整流程均加载真实 Bootstrap，使用同一屏幕坐标拾取入口选择猎物，通过 EventSystem 射线和指针事件点击组队按钮，正式命令队列在 tick 边界执行，之后由正式 Runner 在 8× 下推进。输入检验覆盖引擎的相机拾取与 UI 事件；没有进行 macOS 原生鼠标人工游玩。

- **成功场景**：固定种子 42、两名猎人、成年野猪，初始为温暖季节的受控有效存档。实际完成准备、接近、交战、唯一尸体回收和返村；入库生肉 10、兽皮 2。未在发令后修改生命、位置或阶段。
- **失败场景**：同种子两人队伍与可达长路线，真实追猎期限到达后撤退。逐人核对返回位置／时刻，确认无遗留补给预留。未通过杀死、移动或删除目标制造失败。
- **默认世界**：默认地图、NPC、装备、天气和配置均未修改。自然推进到可组织队伍后，经 UI 自动组队完成一次出发与返回；本次目标为鹿，结果为真实追猎超时后返村，未将其计作成功。
