# 冬日十四天 · HUD 动效

## 实现

沿用冬日四角仪表、Noto Sans SC 中文字体及炭灰／霜白／炉火橙主题。所有改动属于 Presentation 与 UI 验证；未更改 Sim、App 快照、存档格式、世界美术、包依赖或 Bootstrap 场景。

| 行为 | 实现 |
| --- | --- |
| 四角入场 | 180 ms 淡入，挑战／天气／储备／操作依次延迟 0／60／120／180 ms，保持立即可交互 |
| 按钮 | 100 ms 边框提亮与内部内容 1 单位按压；命中矩形不动，禁用和隐藏时复位 |
| 详情与状态卡 | 详情从右侧 8 单位、180 ms 淡入；人物卡下移 4 单位、140 ms 淡入；关闭 120 ms，立即释放射线 |
| 挑战进度 | 320 ms 暖色刻痕强调；一次跨越多日只强调最新完成刻痕，所有刻痕立即正确更新 |
| 天气 | 220 ms 图标交叉淡化；太阳、月亮、雪花三层固定图标保留中断时的可见组合；进入暴风雪／结冰时 600 ms 边缘提示 |
| 储备 | 数值即时，240 ms 变化强调，每种物资一秒冷却；紧张／耗尽转变优先 600 ms 告警，耗尽断刻度以 2.4 秒周期轻微改变透明度 |
| 人物 | 需求条 160 ms 到最新目标；疾病／生命状态变化用独立边框提示，切换人物直接建立基线 |
| 生态与市场 | 种群、出生、死亡、猎获、迁徙和交易行 360 ms 色线反馈；生态列表按物种／群体／区域等稳定标识匹配，栖地生物量按千单位分段以避免逐 tick 闪动 |
| 收起生态面板 | 导航色线 600 ms，最多每五秒一次；隐藏面板持续更新基线，展开不补播 |
| 存档与结算 | 沿用成功四秒、失败持续反馈；结算背景 160 ms、成绩卡 220 ms，锁定和模态阻挡立即生效 |
| 减少动态 | 帮助页开关，默认关，本机持久化；取消位移、循环和分批入场，需求条立即完成，短淡化不超过 80 ms |

`HudMotion` 集中维护时间参数。`PanelTransition` 支持中途反向与即时完成；相同目标不重启。独立 `HudPulse` 装饰不覆盖危险、选中或禁用语义色，不参加射线检测。初始化及世界版本变化清理反馈并重建只读差分基线；失败读档继续使用原世界。

`GodHud` 原查询与控制接口保留，增加 `ReducedMotion` / `SetReducedMotion(bool)` 作为表现层设置入口。设置键为 `MyAiWorld.Hud.ReducedMotion`，不进入游戏存档。
